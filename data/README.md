# Dataset Directory

This directory is reserved for datasets used by CreditLens.

## Dataset Guidelines

- Use a publicly available dataset suitable for educational machine learning.
- Record the original dataset source and its licence before using it.
- Do not upload private banking records or personally identifiable information.
- Do not commit raw datasets unless redistribution is permitted.
- Keep local datasets out of Git using the repository's `.gitignore`.
- Document any data cleaning, preprocessing and feature transformations.

## Planned Data Workflow

1. Obtain the selected public dataset.
2. Inspect its structure and data quality.
3. Handle missing values and inconsistent records.
4. Separate features and the target variable.
5. Split the data into training and testing sets.
6. Train and evaluate the classification model.
